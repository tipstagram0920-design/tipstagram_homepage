# 5주 챌린지 3주차 숙제 페이지

> 작성일 2026-08-02 · 대상: 팁스타그램 5주 멱살잡히기 챌린지 참가자

## 1. 3주차는 어떤 주인가

랜딩 페이지 커리큘럼 기준 3주차는 **"진짜 멱살 잡는 날 — 서울 종로 오프라인 1:1, 1인당 20분 계정 진단"** 입니다.

그래서 3주차 숙제는 **"오프라인 1:1 진단 사전 제출"** 로 만들었습니다.
20분을 자기소개·계정 설명으로 날리지 않고, 처음부터 진단에만 쓰기 위한 사전 자료입니다.

접속 경로: `/challenge/{기수ID}/week/3`

## 2. 참가자가 채우는 항목 (6개 블록)

| # | 블록 | 내용 | 필수 |
|---|------|------|------|
| 1 | 오프라인 1:1 참석 | 참석 / 불참 선택 · 희망 시간대 · 남길 말 | 참석 여부 **필수**, 참석 시 시간대 필수 |
| 2 | 내 계정 현황 | 팔로워 · 최근 30일 도달 · 최근 30일 프로필 방문 · 주력 주제/상품 | 선택 |
| 3 | 2주차 릴스 성과 | 릴스 URL + 조회수·저장·프로필 방문·신규 팔로우 + **내 해석** | **최소 3개** (URL + 조회수) |
| 4 | 지금 가장 막힌 지점 | 어디서 무엇이 끊기는지 서술 + (선택) 챌린지 끝날 때 원하는 상태 | **20자 이상** |
| 5 | 20분 안에 묻고 싶은 질문 | 기본 3칸, 추가 가능 | **최소 2개** |
| 6 | 인사이트 스크린샷 | 프로페셔널 대시보드 캡처 최대 10장 | 선택 |

하단에 기존과 동일하게 **내 인스타 URL**(선택) 입력란이 붙습니다.

### 설계 의도

- **숫자를 4개(조회·저장·프로필 방문·신규 팔로우) 다 받는 이유** — 진짜 병목은 조회수가 아니라 그 다음 칸에서 드러납니다. 조회 3천에 프로필 방문 20이면 릴스 문제가 아니라 프로필 문제입니다.
- **'내 해석' 칸** — 학생이 무엇을 원인이라고 **믿고 있는지** 알아야 그 믿음부터 교정할 수 있습니다. 틀린 해석이 오히려 유용한 정보입니다.
- **질문 최소 2개** — 20분을 무엇에 쓸지 학생이 먼저 정하게 합니다.

## 3. 저장 · 제출 동작

1·2주차와 동일합니다.

- **임시 저장** — 검증 없이 현재 상태 저장, 미제출 유지. 다시 들어오면 그대로 불러옵니다.
- **숙제 제출하기** — 위 필수 조건 통과 시 정식 제출.
- **마감 전까지 수정 가능** — 제출 후에도 "수정 저장하기"로 계속 고칠 수 있습니다.
- **마감 후** — 읽기 전용 뷰로 전환(수정 불가).
- 버튼 옆에 `제출까지 필요: 릴스 성과 2개 더 · 질문 1개 더` 식으로 남은 항목이 실시간 표시됩니다.

## 4. 관리자 쪽에서 보이는 것

- `/admin/challenge/{기수}/weeks/{주차}/submissions` 에서 제출물이 **구조화된 카드**로 보입니다. 참석 여부·희망 시간대가 맨 위에 나오므로 오프라인 일정 잡을 때 그대로 쓰면 됩니다.
- **AI 피드백 초안**도 3주차 전용 관점으로 생성됩니다. 판단 기준:
  1. 숫자를 실제로 확인해 왔는가 (추측·공란이 아닌가)
  2. 지표 사이 병목을 스스로 읽어냈는가
  3. '막힌 지점'이 진단 가능한 수준으로 구체적인가
  4. 질문이 일반론이 아니라 이 계정 고유의 것인가
- 초안은 **미발송 상태**로 저장되고, 관리자가 검토 후 "확인 후 전송"을 눌러야 학생에게 공개됩니다. (자동 발송 없음 — 기존 규칙 그대로)

## 6. 이미 반영된 DB 내용

두 기수(`2026년 7월 기수`, `미리보기 기수`) 모두 3주차에 아래가 들어갔습니다. 일정(오픈일·마감일)은 손대지 않았습니다.

- **제목** — `Week 3 · 진짜 멱살 잡는 날 (오프라인 1:1 진단)`
- **이번 주 안내** — 종로 오프라인 안내 + 사전 작성 요청
- **팁스타그램의 편지** — 숫자를 추측하지 말고 인사이트에서 그대로 옮길 것, 잘 안 된 릴스를 숨기지 말 것, 검색으로 풀리는 질문은 적지 말 것

## 7. 관리자가 지금 확인/조정하면 좋을 것

1. **오프라인 날짜·장소 확정** — 편지에 "서울 종로"만 있고 구체 날짜는 없습니다. `/admin/challenge/{기수}/weeks/{주차}/edit` 에서 편지에 날짜를 넣어주시면 좋습니다.
2. **숙제 마감 시각** — 오프라인 당일보다 최소 2~3일 앞으로 당기는 걸 권합니다. (미리 읽고 가야 진단이 됩니다) 현재는 자동 생성값 그대로입니다.
3. **이번 주 볼 강의 / 참고 영상** — 주차 편집에서 지정 가능하며 현재 비어 있습니다.

## 8. 확인하지 못한 것

- 로그인·수강 등록이 필요한 페이지라 **브라우저에서 실제 화면은 직접 확인하지 못했습니다.** 타입 검사(`tsc --noEmit`)와 린트는 통과했고, 개발 서버에서 해당 라우트가 오류 없이 컴파일되는 것까지는 확인했습니다.
