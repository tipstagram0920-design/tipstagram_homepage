# 5주 챌린지 3주차 숙제 페이지

> 최종 수정 2026-08-02 · 대상: 팁스타그램 5주 멱살잡히기 챌린지 참가자

## 1. 3주차 숙제

**인스타그램에 릴스를 최소 3개 올리고, 각 릴스의 URL을 제출한다.**

오프라인 1:1은 이미 끝난 상태라, 3주차 페이지에서는 오프라인 관련 항목을 모두 뺐습니다.
숙제 페이지는 릴스 URL 제출 하나에만 집중하도록 만들었습니다.

접속 경로: `/challenge/{기수ID}/week/3`

## 2. 참가자가 보는 화면

숙제 입력란은 카드 하나입니다. 릴스 칸이 기본 3개 펼쳐져 있고, 각 칸에 두 줄이 있습니다.

| 입력 | 내용 | 필수 여부 |
|------|------|-----------|
| 릴스 URL | `https://www.instagram.com/reel/...` | **필수** |
| 주제 · 후킹 한 줄 | 이 릴스에서 노린 대상과 첫 3초 후킹 | 선택 |

- **릴스 추가** 버튼으로 4개, 5개도 낼 수 있습니다. (3개 넘으면 삭제 버튼도 생깁니다)
- 제출 조건은 **URL이 채워진 릴스 3개** 하나뿐입니다. 다른 필수 조건은 없습니다.
- 안 채웠으면 버튼 위에 `제출까지 필요: 릴스 URL 2개 더` 라고 실시간으로 뜹니다.

'주제·후킹 한 줄'을 선택으로 둔 이유는, 필수로 걸면 릴스 올리는 것 자체가 밀리기 때문입니다. 다만 적어주면 AI 피드백이 훨씬 정확해져서 편지에서 권유는 하고 있습니다.

## 3. 저장 · 제출 동작 (1·2주차와 동일)

- **임시 저장** — 검증 없이 현재 상태 저장. 다시 들어오면 적던 게 그대로 불러와집니다.
- **숙제 제출하기** — URL 3개 이상이면 정식 제출.
- **마감 전까지 수정 가능** — 제출 후에도 "수정 저장하기"로 계속 고칠 수 있습니다.
- **마감 후** — 읽기 전용으로 전환. 제출한 릴스 링크 목록이 그대로 보입니다.
- 하단에 **내 인스타 URL**(선택) 칸이 기존과 동일하게 붙어 있습니다.

## 4. 관리자 쪽

- `/admin/challenge/{기수}/weeks/{주차}/submissions` 에서 제출된 릴스 링크가 번호 순으로 보입니다. 클릭하면 바로 인스타그램으로 넘어갑니다.
- **AI 피드백 초안**도 3주차용 관점으로 바뀌었습니다. 판단 기준:
  1. 최소 3개를 실제로 채웠는가 (실행량)
  2. 각 릴스의 대상과 첫 3초 후킹이 뚜렷한가
  3. 1주차에 정한 소비자·상품과 릴스 주제가 이어지는가
  4. 3개가 서로 다른 각도인가, 같은 걸 반복했는가
  - 릴스 URL마다 개별 코멘트 + 다음 주 한 줄 액션을 주도록 지시해 뒀습니다.
- 초안은 여전히 **미발송 상태**로 저장되고, 관리자가 "확인 후 전송"을 눌러야 학생에게 나갑니다.

## 5. DB에 반영된 3주차 내용

두 기수(`2026년 7월 기수`, `미리보기 기수`) 모두 반영 완료. **일정(오픈일·마감일)은 건드리지 않았습니다.**

- **제목** — `Week 3 · 릴스 3개 올리기`
- **이번 주 안내** — 오프라인에서 나눈 이야기를 콘텐츠로 옮기는 주 + 숙제는 릴스 3개 URL 제출
- **팁스타그램의 편지** — 핵심 메시지 4개
  - 카메라부터 켜지 말 것 (대상 → 메시지 → 후킹 → 구조 → 컷 리스트를 종이에 먼저)
  - 무에서 창조하지 말 것 (2주차 방식대로 터진 걸 옮겨 심기)
  - 3개를 똑같이 만들지 말 것 (다른 각도 3개)
  - 70점이어도 올릴 것 (한 개도 못 올리는 게 유일한 실패)
